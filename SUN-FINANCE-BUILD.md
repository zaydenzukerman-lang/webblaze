website carried into the new design**. Your job: make the new **Sun Finance** preview have full content
parity with their real site — keep the new design, just make sure nothing from the real site is missing.
**Only work on Sun Finance.** Do NOT change Sun Premium or Sun Mortgage.

Fetch the real pages yourself (WebFetch) to get full, exact content — don't guess.

## Repo & how Sun Finance is built (read carefully)
- Repo: `~/webblaze` (Next.js 16 on Vercel, scope `hbz-holdings`, project `webblaze`).
- **Sun Finance is generated by a Python script: `scripts/gen_pp_rich.py`.** That script builds BOTH
  Sun Finance and Sun Premium. The Sun Finance config is the dict **`PERSONAL`** (its `dir` ends in
  `/public/sunfinance`). Sun Premium is `PREMIUM`.
  - ⚠️ **Shared code in `build(c)` affects BOTH sites.** To add Finance-only content, put it in the
    `PERSONAL` config dict / per-site fields, or branch on the site — never change shared structure in a
    way that alters Premium. If a change is truly Finance-only and awkward in the generator, you may edit
    the generated `public/sunfinance/*.html` directly instead (but then note it's out of sync with the generator).
- Pages currently generated: `index.html`, `how-it-works.html`, `about.html`, `apply.html` + `styles.css`,
  `sitemap.xml`, `robots.txt`, `img/`. Design = navy + orange accent (`#FF822A`), Fraunces/Inter.
- Nav: Home · How It Works · About · Apply (+ "Apply now" button). Footer has a "The Sun Companies"
  cross-link column + a "Company" column. A **Locations** link (→ their /locations/) is already in the top
  util bar + footer.

## Build → deploy → verify (exact steps)
1. Edit `scripts/gen_pp_rich.py` (PERSONAL config / shared builders as needed).
2. `python3 scripts/gen_pp_rich.py`
3. Re-add asset versions (the generator writes version-less refs):
   `sed -i '' 's|href="styles.css"|href="styles.css?v=10"|g' public/sunfinance/*.html`
   and bump images if you changed any (pattern `img/(hero|accent|prod|loc|city|people|about).jpg` → add `?v=4`).
4. `python3 scripts/seo_inject.py`  (adds canonical/OG/LocalBusiness JSON-LD + sitemap/robots; idempotent).
5. `npm run build && git add -A && git commit -m "Sun Finance parity: ..." && vercel --prod --yes --scope hbz-holdings`
6. **Verify LIVE with `curl` (NOT a browser — saves usage):** each page 200, new content/links present.
   (`vercel --prod` may exceed a 2-min foreground limit but still succeeds; run it backgrounded and poll `vercel ls`.)
