## WebBlaze architecture / deploy
- Repo ~/webblaze (Next.js 16 + static demos in public/<slug>/). Served via subdomain proxy src/proxy.ts
  (host-based) + next.config.ts rewrites. DEMOS array in BOTH files:
  orangebeachfish, dunebuggy, sunfinance, sunmortgagefunding, sunpremium, fetchero, thetownagency.
- trailingSlash:false. Pretty URLs `/apply` etc. work; relative asset paths (img/…, styles.css) — keep relative.
- Build/deploy: `npm run build && git add -A && git commit && vercel --prod --yes --scope hbz-holdings`.
- Generators: scripts/gen_pp_rich.py (Premium+Finance), scripts/gen_mort_rich.py (Mortgage — out of sync),
  scripts/seo_inject.py (adds SEO tags + sitemap/robots; RE-RUN after any regen; idempotent).
- CSS cache-bust: generators write `styles.css` version-less; sed `?v=N` into HTML after regen. Bump on CSS change.
- DNS: Cloudflare (token ~/.cf_webblaze_token, zone webblaze.io 38f5574d3d2e456ed8f24ba23682d395). New subdomain =
  add CNAME → cname.vercel-dns.com (DNS-only) + `vercel domains add <sub>.webblaze.io --scope hbz-holdings`.
- Pexels API key (image sourcing): 85gzYeGliCl062HE8cT3bQZRphoW2iaH9pI2oxmLxJ7zE1KTttQe8eXL
  (Authorization header + a normal User-Agent, else 403). No brand names in photos; premium only.
- Known CSS gotcha (fixed 2026-07): clamp()/calc() REQUIRE spaces around `+`/`-` (`1.7rem + 3.6vw`),
  or the declaration is dropped and text falls back to tiny defaults. Never write `1.7rem+3.6vw`.
