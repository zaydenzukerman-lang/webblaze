## Personalization checklist (before every send)
- Real first name of the owner (find on About page / LinkedIn).
- ONE true, specific observation about their current site (from the scanner flags or the screenshot).
- Correct business name + a working link.
- If using Template A, the preview link actually loads and looks good on mobile.

## GREETING RULE (2026-08-31)
- Personal/named address (e.g. ksmall@, jsmith@, firstname@) → "Hi <FirstName>,"
- Generic/role inbox (mail@, info@, office@, contact@, or businessname@gmail.com) → "Hi <Business> team,"
- Contact-form message to a small owner-run shop → owner first name is fine (it reaches them directly).
